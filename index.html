🔗 Setup Google Drive Sync
Dengan Drive sync, semua data tersimpan di Google Sheet milik RKT. Semua HP tim yang login akan baca data yang sama secara real-time.
Cara Setup (lakukan sekali)
1Buka script.google.com di browser komputer/HP kamu
2Klik New Project → hapus kode lama → paste kode di bawah → Simpan
3Klik Deploy → New Deployment → Web App. Set Execute as: Me dan Who has access: Anyone. Klik Deploy.
4Copy URL yang muncul, paste di bawah ini:
Web App URL
🗑️ Reset Daftar Barang?
Semua SKU akan dihapus. Transaksi dan order yang sudah ada tetap tersimpan.
Gunakan ini jika file Excel yang diimport salah dan mau upload ulang dari awal.
Ketik HAPUS SKU untuk konfirmasi
⚠️ Reset Semua Data?
SEMUA data akan terhapus permanen: SKU, transaksi, order, aktivitas. Tidak bisa dibatalkan.
Ketik HAPUS SEMUA untuk konfirmasi
